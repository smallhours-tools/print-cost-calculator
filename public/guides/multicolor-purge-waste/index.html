How much filament does multicolor printing waste?

Every time a multicolor printer switches filament, it has to push out the old color before the new one comes out clean. That purged filament goes into a wipe tower, a purge chute or the infill, and on small multicolor prints it can be most of the filament you buy. Here is a real example and how to check your own.

A real example: 70% to the wipe tower

The PrusaSlicer source repository includes a test print sliced for an Original Prusa MK3 with the 5-filament MMU2, in five colors of ABS, about 8 h 36 min long. Its G-code ends with these lines:

; filament used [g] = 6.80, 33.23, 19.64, 6.12, 2.88
; total filament used [g] = 68.66
; total filament used for wipe tower [g] = 47.82
PartFilamentShareCost at 26.99/kg
Wipe tower47.82 g70%1.29
Everything else (the model)20.84 g30%0.56
Total68.66 g100%1.85

26.99 per kg is the filament price set in the file's own profile; the slicer's total filament cost line says 1.85, matching the total. The per-filament figures add up to 68.67 g; the total line says 68.66 because of rounding.

For every gram that ends up in the model, this print spends 2.3 g on the wipe tower. The profile purges 140 mm³ of filament at every color change (its wiping_volumes_matrix), which is only about 0.15 g each time at ABS's 1.08 g/cm³, but a print with many color changes on many layers adds that up fast.

Find the number for your own print

  • PrusaSlicer and OrcaSlicer G-code: search the end of the file for total filament used for wipe tower [g].
  • Other slicers: compare the filament total of the multicolor slice with a single-color slice of the same model. The difference is the purge and tower cost.

Pricing it

The slicer's filament total already includes the wipe tower, and the calculator reads that total from the file. So keep the calculator's waste percentage for what the slicer can't see, such as failed prints and trimmed supports, and don't add the tower a second time. If you enter weights by hand, use the slicer's total, not the model's weight: in the example above that is 68.66 g, not 20.84 g.

Ways to waste less

  • Print several parts in one job. The tower is built once per layer, however many objects share it, so the waste per part drops.
  • Fewer color changes. Changing color at a few layer heights costs far fewer purges than changing on every layer.
  • Purge into something useful. Slicers can flush into an object's infill or into a sacrificial object instead of the tower; check your slicer's multi-material settings.
  • Tune purge volumes. Light-to-dark changes need less purging than dark-to-light. Lower the volumes only after test prints show clean colors.
