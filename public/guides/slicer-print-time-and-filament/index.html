Where to find print time and filament weight in G-code and 3MF files

When a slicer exports a print, it writes its own estimate of the print time and the filament used into the file. You can read those numbers back without opening the slicer, which helps when you price an old job, check a file someone sent you, or batch-cost a folder of prints. Each slicer does it differently, though: different places, different units, and sometimes no weight at all.

Every example below is copied from a real, public file (listed under Sources). G-code is plain text, so you can open it in any text editor and search for the line.

PrusaSlicer, SuperSlicer and OrcaSlicer G-code

The totals are comments near the end of the file. This is from a PrusaSlicer 2.9 file:

; filament used [mm] = 4069.40
; filament used [cm3] = 9.79
; filament used [g] = 10.18
; total filament used [g] = 10.18
; estimated printing time (normal mode) = 1h 20m 43s

OrcaSlicer writes the same keys (it descends from PrusaSlicer) and also repeats the print time near the top of the file. With several extruders, each line holds one value per extruder, separated by commas.

Watch out: if the filament profile has no density set, the slicer writes filament used [g] = 0.00. Then multiply the [cm3] figure by your filament's density (see filament cost per gram).

PrusaSlicer binary G-code (.bgcode)

Newer Prusa printers use binary G-code. It holds the same keys as above, but in compressed metadata blocks at the start of the file, so a text editor shows nothing useful. Open it in PrusaSlicer's G-code viewer, or drop it into the calculator, which reads those blocks in your browser.

Cura (Marlin and Klipper printers)

Cura puts its totals at the top, as print time in seconds and filament as a length in meters, with no weight:

;FLAVOR:Marlin
;TIME:870
;Filament used: 1.08208m

The ;TIME_ELAPSED: lines further down are progress markers for each layer, not the total. To get grams from the length, multiply by the filament's cross-section and density:

grams = length in cm × π × (diameter ÷ 2)² × density, with the diameter in cm (1.75 mm = 0.175 cm) and the density in g/cm³.

PLA densities in slicer profiles run from about 1.22 to 1.32 g/cm³, so the grams depend a little on which you use. The calculator uses 1.24 for PLA when the file gives no weight and tells you the weight was estimated.

Cura for UltiMaker printers ("Griffin" flavor)

For UltiMaker printers, Cura writes a different header: time in seconds and filament as a volume in cubic millimeters, one line per extruder:

;FLAVOR:Griffin
;EXTRUDER_TRAIN.0.MATERIAL.VOLUME_USED:76525
;PRINT.TIME:92579

Divide the volume by 1,000 to get cm³, then multiply by the density: 76,525 mm³ is 76.525 cm³, which is 94.89 g at 1.24 g/cm³. The time, 92,579 seconds, is 25 h 42 min.

Bambu Studio and OrcaSlicer 3MF exports

A sliced 3MF (Bambu Studio's "Export plate sliced file", usually named .gcode.3mf) is a zip archive. Rename a copy to .zip to look inside. The totals are in Metadata/slice_info.config, one <plate> section per sliced plate:

<metadata key="prediction" value="843"/>
<metadata key="weight" value="3.69"/>
<filament id="1" type="PLA" used_m="1.22" used_g="3.69" ... />

prediction is the print time in seconds (843 s is 14 min 3 s) and used_g the grams for each filament. For a project with several plates, add the plates up: the calculator does this for you, as in the two-plate example in the filament guide.

A 3MF saved as a project before slicing has no prediction at all, and a plain model 3MF has no print data. Slice it and export the sliced file first.
